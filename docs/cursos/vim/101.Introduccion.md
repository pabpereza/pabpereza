# Introducción a Vim: El Editor Modal

¡Bienvenidos al mundo de Vim! Si estamos aquí, probablemente hayamos escuchado que Vim es difícil, que no se puede salir de él (¡`:q!` es nuestro amigo!), o que es solo para hackers de películas. La verdad es que Vim es una herramienta increíblemente poderosa que, una vez dominada, hará que editar texto se sienta como un superpoder.

## ¿Qué es Vim y por qué debería importarnos?

Vim (Vi IMproved) es un editor de texto **modal**. A diferencia de editores como VS Code o Notepad, donde siempre estamos escribiendo, en Vim tenemos diferentes "modos" para diferentes tareas.

### Los Modos Principales

1.  **Modo Normal (Normal Mode)**: Es donde empezamos. Aquí las teclas no escriben texto, sino que ejecutan comandos. Es para navegar y manipular texto.
    *   `Esc`: Vuelve siempre a este modo.
2.  **Modo Insertar (Insert Mode)**: Aquí es donde escribimos texto, como en cualquier otro editor.
    *   `i`: Entra en modo insertar antes del cursor.
    *   `a`: Entra en modo insertar después del cursor.
3.  **Modo Visual (Visual Mode)**: Para seleccionar texto.
    *   `v`: Selección por caracteres.
    *   `V`: Selección por líneas.

## Movimientos Básicos: Olvida las Flechas

En Vim, intentamos no mover las manos de la fila central del teclado.

*   `h`: Izquierda
*   `j`: Abajo
*   `k`: Arriba
*   `l`: Derecha

Al principio se siente raro, ¡pero démosle una oportunidad!

## Comandos Esenciales para Sobrevivir

Aquí tenemos nuestro kit de supervivencia:

*   `:w` -> Guardar (Write)
*   `:q` -> Salir (Quit)
*   `:wq` -> Guardar y Salir
*   `:q!` -> Salir sin guardar (¡Importante!)
*   `u` -> Deshacer (Undo)
*   `Ctrl + r` -> Rehacer

## Nuestro primer ejercicio

1.  Abramos nuestra terminal y escribamos `vim prueba.txt`.
2.  Presionemos `i` para entrar en modo insertar.
3.  Escribamos "Hola mundo desde Vim".
4.  Presionemos `Esc` para volver a modo normal.
5.  Escribamos `:wq` y presionemos Enter.

¡Felicidades! Hemos creado y guardado nuestro primer archivo con Vim.
